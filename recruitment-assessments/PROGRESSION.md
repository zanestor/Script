# Recruitment Assessment Series — Continuity Tracker

Series purpose: daily briefing + self-contained mock exam for progressively harder
recruitment assessments covering entry-level and mid-level finance roles across a
multi-country donor-funded organization (Tanzania/IPSAS, Uganda & Rwanda/IFRS for
SMEs, DR Congo/OHADA-SYSCEBNL).

This file is the single source of truth for continuity. Read it before writing a new
day's briefing. Update it (append, never rewrite history) after each day.

## Rotation logic

- Country track rotates: Tanzania → Uganda → Rwanda → DR Congo → repeat, so each
  framework gets sustained, progressive depth rather than being touched once.
- Difficulty is a **level counter per country track**, not per calendar day — it only
  increases when the prior day's mechanics for that track have been exercised.
- A **Boss Level** is inserted after every 5th ordinary level within a track (Level 6,
  11, 16 …) — open-ended, 3-hour simulation, problem count undisclosed.
- Recurring mechanics (deferred grant income, pooled bank/anti-commingling, analytical
  dimensions, virtual donor cash, staff imprests, partner advances, cross-country
  travel, intercompany, multi-currency/FX, donor FX reconciliation, tax, prepayments/
  accruals, fleet & mileage, shared-cost/full-cost-recovery, management fee/ICR,
  own-means availability, project financial statements, consolidation, financial vs
  MEAL/narrative, ex-ante/ex-post budget control, ineligible-cost transfers) are
  introduced gradually — do not front-load all of them into Level 1. Each entry below
  lists which mechanics were newly introduced vs. carried forward.
- FX mechanics (transaction/functional/donor-reporting/bank/presentation currency,
  realized/unrealized FX, donor-specific FX methods, FX effect on available-to-commit,
  FX exposure of own means) are introduced the same way — gradually, then reused.
